# make FLAMES python package venv

make FLAMES python package venv

## Usage

``` r
make_flames_venv(
  environment_name = "coloclize_flames_env",
  environment_path = tempdir()
)
```

## Arguments

- environment_name:

  name of the environment to create

- environment_path:

  path to create the environment in

## Value

list with environment name and path
