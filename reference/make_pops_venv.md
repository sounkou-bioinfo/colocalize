# make pops python package venv

make pops python package venv

## Usage

``` r
make_pops_venv(
  environment_name = "coloclize_pops_env",
  environment_path = tempdir()
)
```

## Arguments

- environment_name:

  name of the environment to create

- environment_path:

  path to create the environment in

## Value

list with environment name and path
